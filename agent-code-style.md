# Требования к кодстайлу для агентов

Правила обязательны для всех агентов и применяются всегда: ко всем новым, изменяемым и проверяемым C#-файлам проекта Unity.

## Именование

- Приватные поля именуются в `camelCase` с префиксом `_`: `_poolRoot`, `_activeEnemies`.
- Константы именуются в `UPPER_SNAKE_CASE`: `TARGET_DISTANCE`, `MAX_SPAWN_ATTEMPTS`.
- Публичные типы, методы и свойства именуются в `PascalCase`.
- События именуются в `PascalCase` с префиксом `On`: `OnCurrentWaveChanged`, `OnCompleted`.
- Параметры методов и локальные переменные именуются в `camelCase`.
- `CancellationToken` именуется `ct`, а `CancellationTokenSource` — `cts`; поле источника токена использует имя `_cts`.
- Интерфейсы начинаются с `I`: `IPoolable`.

## Общие правила

- Каждый публичный класс размещать в отдельном файле; имя файла совпадает с именем публичного класса. Приватные вложенные типы допускаются.
- Не создавать общие папки `Scripts`, `Code` или `Source`. Размещать код в папке соответствующей фичи/механики рядом с её prefab, asset и другими ресурсами.
- Организовывать `Assets` по фичам и игровым механикам, а не по типам ресурсов. Не создавать папки наподобие `Scripts`, `Prefabs`, `Textures` как основной уровень иерархии.
- Хранить общие механики ближе к корню `Assets/Game`, а частные ресурсы — ниже, рядом с объектом, которому они принадлежат. Например, папка `Enemies` содержит код и prefab врагов; уникальные ресурсы конкретного врага хранятся в его собственной подпапке.
- Хранить скрипты рядом с prefab и ресурсами соответствующей механики или объекта.
- Не использовать `static`-состояние для игрового сценария, пула, волн или UI.
- Не вызывать `Instantiate`, `Destroy` и `SetActive(false)` вне `PoolManager`.
- Не добавлять физику, коллайдеры и `Rigidbody2D` врагам.
- Зависимости передавать через конструктор или VContainer `[Inject]`; не искать объекты через `Find...`.
- Не добавлять лишние зависимости и не менять архитектурные контракты без явной необходимости.
- После изменений проверять лinter-ошибки и исправлять введённые нарушения.
